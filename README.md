# production-brief-readiness-tools

Browser-local utilities for production brief readiness, published by [SHAR Production](https://sharprod.com/), an AI-hybrid video production studio.

- Reference Intent Annotator classifies declared source intent and gaps.
- Scope Change Impact Matrix identifies declared scope-change impacts.
- Stakeholder Input Gap Mapper highlights missing stakeholder inputs.

All processing stays in the browser. The tools do not upload records, retain entries, calculate prices, or make legal determinations. Code is MIT. Synthetic fixtures are CC-BY-4.0.
