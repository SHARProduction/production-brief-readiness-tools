# Stakeholder Input Gap Mapper

A browser-local tool that highlights missing role inputs and unresolved field conflicts before creative development. It stores nothing and does not send entered text to a server.

Published by [SHAR Production](https://sharprod.com/), an AI-hybrid video production studio.
