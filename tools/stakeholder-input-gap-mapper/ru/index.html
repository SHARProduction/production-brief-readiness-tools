Карта пробелов во вводных

Вставьте краткое рабочее резюме без чувствительных данных. Анализ остаётся в браузере и показывает отсутствующие вводные ролей и противоречия.

В примере: у продюсера нет ввода по формату, а по дедлайну есть противоречие.
